A smart, lightweight web application that provides real-time weather updates, a 7-day forecast, and AI-powered daily planning recommendations based on current meteorological conditions. 

## Features
* **Real-Time Weather Data:** Fetches current conditions for any searched city using the free, keyless Open-Meteo API.
* **7-Day Forecast:** Displays a detailed upcoming weather outlook.
* **Smart Planning Recommendations:** Utilizes the Google Gemini API to generate personalized, 2-sentence outfit and activity suggestions based on the weather data.
* **Responsive Dashboard:** Built with HTML, CSS, and TypeScript for a fast, intuitive user experience.

## Tech Stack
* **Frontend:** HTML, CSS, TypeScript
* **Build Tool:** Vite
* **Weather Data:** [Open-Meteo API](https://open-meteo.com/)
* **AI Integration:** Google Gemini API
